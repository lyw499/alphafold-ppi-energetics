# Supplementary distributional test

For four raw-Pedro comparisons, the observed statistic is sup_x |F_P(x)−F_E(x)| over the union of count support. Resample entire Pedro job-name / experimental PDB clusters independently 2000 times. The centered null empirical process is (F*_P−F_P)−(F*_E−F_E); take its supremum absolute value. Monte Carlo p=(1+number of bootstrap suprema ≥ observed D)/(2001). This is an approximate centered cluster-bootstrap KS test, not the standard iid KS p-value and not a label-permutation test. Seed 20261025. The independent-cluster and empirical-process approximation assumptions remain; shared proteins and selection limit inference. Holm adjustment across these four supplementary tests is separate from the four primary mean-log-count tests. When no replicate exceeds the statistic, p=1/2001 is the simulation floor, not proof of an exact p=0.00049975 or a lower bound on the true p.

This supplement tests an omnibus distribution discrepancy; it does not distinguish zero inflation, location and shape, adjust interface area, establish causality or prediction accuracy. Sources are standardized_interfaces.csv.gz and the same frozen count definitions. It does not rerun parsing, structure calculations, or primary inference.
