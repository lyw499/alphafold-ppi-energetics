# FoldBench AF3 matching audit

原始 279 个实验接口（239 个 assembly），匹配 132，未匹配 147。

逐条重新检查官方接口行、实验链存在性、完整 AF3 归档成员清单（136,200 个 PDB / 681 targets / 每个 200 个模型）、摘要清单及本地所选 AF3 坐标。所有 132 个已有配对重新通过序列 identity ≥0.95、实验观测序列 coverage ≥0.90 的核验。

147 个未匹配接口全部对应 **131 个 PDB/assembly 在所提供归档中缺失**。大小写归一化及同 PDB 的其他 assembly / `_chain_ligand` 变体搜索也没有命中。不是链 ID mismatch、序列映射失败或 parser 错误造成的 147 条损失。缺文件时 B/C/D 无法评估，不能宣称缺少某蛋白序列，也不能将其计为零。这里证明的是本地提供归档的缺失，不证明任何其他公共来源也没有预测。

现有归档是 Zenodo 21947583 的 Thal-Kak AF3 子集，不是原 FoldBench 全部预测。缓存 Zenodo 元数据明确声明 681 targets；下载校验记录与成员清单一致。本次复用已有完整清单，不重复解压 11 GB 归档。

未发现能恢复这些缺失目标的匹配代码错误，因此没有改写原映射程序，也没有为增加 n 强制匹配。最终仍为 **132 匹配 / 147 未匹配**。链 ID 差异已由序列及全复合体 CA 几何映射处理。

132 是可映射集合，并不都唯一：几何并列涉及 23 个接口，其中 14 个至少一个链级或接口指标敏感，6 个残基对计数敏感。保留原确定性映射、全部并列候选及单独的映射稳定敏感性分析，不把这些不确定性伪装成缺文件。几何拟合本身不证明生物学对应关系，且可能使结构比较偏乐观。

配对分析仅使用上述 132 条，两侧采用同一接口集合；有效 AF3 零接触保留。缺失 147 条仍在审计和全集结果表中。抽样覆盖偏差与同一 assembly 多个相关接口仍需说明。

审计逻辑检查：279 = 132 + 147；131 个缺失 assembly 对应147条接口；所有有文件的指定链对均通过序列复核；不存在同 PDB 变体可恢复目标；缺失值没有转零。审计完成后才进入后续残基比较。
